# Macro Shield activation

1. Download MacroShield.exe from the latest release.
2. Open Settings → Activate Macro Shield.
3. Copy your PC Code and send it privately to the app owner using the contact information shown inside the app.
4. The owner registers your license online and sends your individual code or .lic file.
5. Paste or import the code, then click Activate while online.

Your license may be Lifetime or have a specified expiry. A days-based license runs from when it is issued, rather than from first activation.

The current client requires an explicit signed Active registration. Missing registrations are blocked. Deleted licenses are permanently Revoked. A revoked license cannot be reactivated using the manager; the owner must issue a new license to restore access. A client that has observed permanent revocation keeps blocking that license even if the online entry disappears or later says Active.

The app verifies online status at startup, before processing and periodically while open. First verification requires internet. Previously verified active licenses have up to 24 hours of offline grace during network outages. Known revoked licenses remain blocked offline. Remote changes can take several minutes because of check intervals and GitHub caching. An offline PC cannot receive a new status immediately.

Use the latest client for the current revocation protections. Existing signed activation is preserved when updating, but earlier licenses absent from the registry must be imported and published by the owner. Updates replace the existing executable; Excel originals remain unchanged and output copies use the automatic _mnrd naming.

Only the client EXE and your individual license file are needed. The private owner's License Manager, password/recovery information, signing keys, license history and GitHub token are never part of the client download. Recipient names, PC Codes and activation codes are not published in the status files.
