# Macro Shield activation — v1.0.2 and later

1. Download MacroShield.exe from the latest release.
2. Open Settings → Activate Macro Shield.
3. Copy your PC Code and send it privately to the app owner using the contact information shown inside the app.
4. Paste the license code received from the owner, or import your individual .lic file, then click Activate while online.

Your license may be Lifetime or have a specified expiry. A days-based license runs from the time it is issued, rather than from first activation.

The app verifies a signed online license status at startup, before processing and periodically while open. After a successful verification, an active license has up to 24 hours of offline grace. First verification needs internet. A known suspended or deactivated license remains blocked offline. Remote changes can take several minutes because of check intervals and GitHub caching. An offline PC cannot receive a status change immediately.

Earlier offline versions must upgrade to support online license control. Existing signed activation is preserved when updating. Updates replace the existing executable; Excel originals remain unchanged and outputs use the automatic _mnrd copy naming.

Only the client EXE and your individual license file are needed. The owner's License Manager, signing keys, private history and GitHub token are never part of the client download.
